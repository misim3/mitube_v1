# Mitube

유튜브를 모티브로 한 영상 콘텐츠 공유 플랫폼

> 영상 공유 플랫폼: 기능 → 성능 → 구조 개선으로 발전한 프로젝트

## 📦 버전별 개발 단계

- **v0**: 필수 기능 구현 (회원가입, 댓글, 조회수, 영상 업로드/시청 등)
- **v0.5**: Redis 캐싱, MySQL Replication 도입
- **v1.0**: 구조 단순화 + 통합 테스트 + 코드 리팩토링

## 🔧 기술 스택

- Java, Spring Boot, MySQL
